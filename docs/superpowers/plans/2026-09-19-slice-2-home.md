# Slice 2 - Home Page Implementation Plan (lean process)

> One Sonnet implementer builds the whole slice; the controller checks it visually against amazon.com (user decision: leaner slices).

**Goal:** Replace the placeholder home page with Amazon's home page on desktop and mobile web: hero carousel, category card grid overlapping the hero, and the signed-out "See personalized recommendations" band.

**Spec:** `docs/spec.md` 5.3 and 5.13; `docs/design.md` 6.2. Recon: `docs/recon/1_initial-home-page-desktop-scroll-1..8.png`, `docs/recon/mobile-app-views-captured/*` (the whole folder is the mobile home page, top to bottom).

## Global Constraints (same as Slice 1)

- Match amazon.com exactly. Colours only via tokens in `app/globals.css` (add tokens there); no hex in components. No emojis, no long dashes.
- Every Amazon image URL lives in `lib/assets.ts` or `lib/content/home.ts` (content file); nothing inline in components.
- The page is shared content: cache it (`'use cache'` + `cacheLife("days")` + `cacheTag("home")`); anything reading cookies stays inside `<Suspense>` (the layout already does this for the header).
- Commands `npm test`, `npm run lint`, `npm run typecheck`, `npm run build` must pass. Commit with `.agent-logs/` changes, message ending `Co-Authored-By: Claude Sonnet 5 <noreply@anthropic.com>`. Do not push.

## Task 1: Home page

**Files:** create `lib/content/home.ts`, `components/home/HeroCarousel.tsx` (client), `components/home/HomeCard.tsx`, `components/home/SignInBand.tsx`, `components/home/HomeMobile.tsx` (or mobile variants of the same components); replace `app/(shop)/page.tsx`; test `tests/unit/content/home.test.ts`; script `scripts/check-home-links.ts` (see step 3).

**Content capture (do this first):** open https://www.amazon.com/ with the Claude in Chrome browser tools, stay signed out, and record the current hero slides (image URL with its `._SX3000_` suffix, alt text) and the category cards from the top of the page downwards (at least 16 cards: title, card type, tile image URLs and labels, footer link text such as "See more" or "Shop now"). Strip query strings from URLs. Card types on Amazon: a 2x2 grid of labelled tiles, a single large image with a footer link, or a 1+3 layout; reproduce whichever types the captured cards use. If a card needs a product line we don't have (our 12 departments: Baby, Beauty & Personal Care, Books, Clothing Shoes & Jewelry, Computers, Electronics, Home & Kitchen, Pet Supplies, Sports & Outdoors, Tools & Home Improvement, Toys & Games, Video Games), skip that card and take the next one, so every tile leads to real products.

**`lib/content/home.ts`:**
- `heroSlides: { image: string; alt: string; href: string }[]`
- `homeCards: HomeCard[]`, where each card has `title`, `href`, `footerLabel`, and either `tiles: { label; image; href }[]` or `image` (single-image card).
- Every `href` is internal: `/s?k=<query>&i=<department-slug>` or `/s?i=<department-slug>`, chosen so the search returns products from our catalogue.

**Layout (desktop, from 768px, measured from the recon and live site):**
- The page background is `bg-page-bg`, with content centred at max width 1500px.
- **Hero:** full width at a 3000:1200 aspect (show the top 600px or so, like Amazon), with a gradient that fades the bottom into `page-bg`. Left and right arrow buttons are 80px wide, tall, and transparent, with a thin white chevron SVG and a focus outline. It auto-advances every 5s, pauses on hover and focus, and responds to the arrow keys. Each slide links to its `href`.
- **Card grid:** overlaps the hero by about 250px (negative margin on a relative container). There are 4 cards per row at 1280px, with a 20px gap and 20px side padding.
- **Card:** white, no radius, padding 20px 20px 15px. Title 21px, bold, line-height 27px, `text-text`. Tiles are a 2x2 grid with square images (object-fit cover, background `#f7f7f7` as token `--color-tile-bg`), labels 12px `text-text`. The footer link is 13px `text-link` ("See more", hover `text-link-hover` underline), and the whole title links to `href`.
- **Signed-out band** after the cards (always shown in this slice; Slice 6 switches it on the session): a white strip with a top border, "See personalized recommendations" (21px bold, centred), a yellow `Sign in` button 250px wide linking to `/ap/signin`, and "New customer? " + link "Start here." to `/ap/register` (11px).

**Layout (mobile, below 768px, from `docs/recon/mobile-app-views-captured`):**
- Hero carousel full-bleed at the mobile aspect, swipeable (pointer drag or scroll-snap), no arrows.
- Then the "Sign in for the best experience" band: 20px bold heading, a full-width yellow "Sign in securely" button (`/ap/signin`), and a "Create an account" link (`/ap/register`).
- Then one card per row, full width with 16px padding: title 20px bold with a chevron on the right linking to the card; a 2x2 image grid with labels under the images.
- The last block is "Explore Departments" (a card whose tiles are our departments, linking to `/s?i=<slug>`).
