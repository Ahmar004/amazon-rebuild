# Slice 5 - Cart Implementation Plan (lean process)

> One Sonnet implementer builds the whole slice; the controller checks it visually against amazon.com.

**Goal:** A working cart for guests (and, from Slice 6, signed-in users): Add to cart from the product page and search rows, the added-to-cart page with the mini-cart rail, the Shopping Cart page with quantity, delete, save for later and share, and a live cart count in the header.

**Spec:** `docs/spec.md` 5.6, 6.1, 6.6; `docs/design.md` 4 (carts, cartItems, guest state), 5.2 (`guest.ts`), 5.3 (`cart.ts`), 6.5. Recon: `docs/recon/3-add-to-cart-*.png`, `docs/recon/4-shopping-cart-scroll-1..3.png`.

## Global Constraints

- Match amazon.com exactly: check the live cart and added-to-cart pages with the Claude in Chrome tools, signed out, after adding any cheap item. Colours only via tokens; no hex in components; no emojis or long dashes; no "Sponsored" labels.
- Money in integer cents, computed on the server (`getCart` returns the subtotal); the client never computes money.
- Data only through `lib/data/cart.ts`. Every function takes a `CartOwner = { userId: string } | { guestToken: string }` and filters by it in SQL. No function lets one owner touch another owner's cart.
- The guest cart token lives in the cookie `cart_token`, HMAC-signed with `SESSION_SECRET` (`lib/auth/guest.ts`: `getGuestToken()` verifies the signature and returns null when it's tampered with; `ensureGuestToken()` creates one). Anything reading cookies renders inside `<Suspense>` and never inside `'use cache'`.
- Server Actions in `actions/cart.ts` validate input with Zod, cap the quantity at `min(stock, 30)`, refuse unknown or out-of-stock products, and after each write refresh what the header shows (read how in `node_modules/next/dist/docs/` under Server Actions and caching: `refresh()`, `updateTag`, `revalidatePath`).
- TDD for `guest.ts`, the cart data layer's pure logic, and the action validation. Test, lint, typecheck and build must pass. Commit with `.agent-logs/` changes, message ending `Co-Authored-By: Claude Sonnet 5 <noreply@anthropic.com>`. Do not push.

**Contracts (Slices 6-8 depend on these):**
- `CartView = { lines: CartLine[]; saved: CartLine[]; subtotalCents: number; itemCount: number }`, where `CartLine = ProductSummary & { quantity: number; lineTotalCents: number; maxQuantity: number }`, `itemCount` sums the quantities of non-saved lines, and `subtotalCents` covers only non-saved lines.
- `getCart(owner)`, `addItem(owner, asin, qty)` (adds to an existing line; caps at `min(stock, 30)`; moves a saved item back into the cart), `setQuantity(owner, asin, qty)` (0 deletes the line), `removeItem(owner, asin)`, `setSaved(owner, asin, saved)`, `cartCount(owner)`, and `mergeGuestCart(guestToken, userId)` (implement and test it now; Slice 6 calls it. Quantities add up, capped; the guest cart is deleted afterwards).
- `actions/cart.ts`:
  - `addToCart(input: { asin: string; quantity: number; redirectTo: "smart-wagon" | "none" })`: `"smart-wagon"` redirects to `/cart/smart-wagon?asin=<asin>&qty=<n>`, `"none"` returns `{ ok: true, count }`.
  - `updateQuantity(asin, qty)`, `deleteItem(asin)`, `saveForLater(asin)`, `moveToCart(asin)`. Each returns `{ ok: true } | { ok: false; error: string }`.
